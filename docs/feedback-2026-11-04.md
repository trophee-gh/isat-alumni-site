## Answers to the questions (for the captain's reply to Alvin)

- **Where the data lives, does it update itself:** the annuaire is a file in the site's repository
  (`src/annuaire/annuaire.json`, opt-in entries only); the figures are aggregates written into the pages. A change
  to the file rebuilds and republishes the site by itself; adding the new promos is a file edit. An Ohme link is
  possible later (above).
- **Netlify:** the host that builds and serves the site from its repository. The site can be served on
  `alumni-isat.fr` with no "netlify" in the address. Hosting a site this size is free on Netlify's free plan
  [I: plan limits to check on netlify.com/pricing]; the domain itself is a yearly fee at the registrar.
- **Terms of use:** no general terms are needed for a showcase with no accounts; the legal notices and the privacy
  note are (F26).
